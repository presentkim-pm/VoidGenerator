# VoidGenerator

A chunk generator plugin for PocketMine-MP that creates empty (void) chunks, so a world contains nothing but air.

> [!WARNING]
> This project is archived and no longer maintained.
>
> **Reason:** axolotl-pm/PocketMine-MP 5.48 and later ship a void generator in the core.
>
> **Replacement:** The core void generator in axolotl-pm/PocketMine-MP 5.48+.
>
> It targets the old PocketMine-MP API 4.0.0 (see `plugin.yml`) and will not work on axolotl-pm/PocketMine-MP 5.51.
